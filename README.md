# Glassmorphism Login Form UI Design

Um componente de formulário de autenticação (Login Form) moderno, imersivo e totalmente responsivo que adota a estética do Glassmorfismo (Glassmorphism). Desenvolvido exclusivamente com HTML5 e CSS3, o projeto utiliza efeitos avançados de desfoque de fundo e opacidade para criar um card com textura de vidro fosco flutuando sobre uma imagem hero em tela cheia.

## Tecnologias Utilizadas

* HTML5: Estruturação semântica do formulário de acesso, campos de entrada (`<input>`), caixas de seleção e links utilitários.
* CSS3: Estilização completa, uso de filtros de desfoque avançados, gerenciamento de opacidade translúcida e cantos suavizados.
* Flexbox: Centralização absoluta do card de login na viewport e alinhamento horizontal dos elementos de suporte.

## Funcionalidades e Técnicas Aplicadas

* Efeito Glassmorphism de Alta Fidelidade: O card de login aplica a propriedade `backdrop-filter: blur()` combinada com um fundo branco semi-transparente (`rgba`) e uma borda fina sutil, simulando com precisão uma placa de vidro jateado.
* Inputs Minimalistas com Linha Inferior: Os campos de credenciais ("Enter your email" e "Enter your password") abandonam as caixas tradicionais, adotando um design limpo baseado apenas em linhas inferiores brancas e placeholders discretos.
* Botão de Ação Sólido de Alto Contraste: O botão "Log In" possui preenchimento branco sólido com texto escuro, oferecendo um excelente contraste visual e uma chamada para ação (CTA) imediata e convidativa ao clique.
* Opções de Suporte Alinhadas: Inclusão de uma linha de utilitários contendo uma checkbox customizada para "Remember me" perfeitamente alinhada ao link "Forgot password?".
* Background Imersivo em Tela Cheia: Otimização da imagem de fundo (paisagem de montanhas sob iluminação dramática) usando `background-size: cover` para preencher as dimensões da tela de forma responsiva, servindo como a textura ideal para realçar o desfoque do vidro.
